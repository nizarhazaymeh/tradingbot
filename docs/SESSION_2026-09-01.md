## Bugs found by running live — 8, all fixed

Every one of these was invisible in dry-run:

1. **Stale-quote pricing.** Orders were priced from the chain fetched at the start
   of the cycle. The first live order asked \$0.25 credit when, seconds later, the
   market offered \$0.14. It never filled. Now quotes are refreshed immediately
   before pricing, and a fill-chasing ladder replaces the order at progressively
   worse prices until it fills.
2. **Orphan-creating NameError.** A stale variable reference raised *after* the
   order reached the broker but *before* it was recorded — leaving a live 4-leg
   condor with no exit plan. Since Alpaca has no bracket orders on options, that
   monitor loop is the only stop-loss.
3. **Positions recorded on submit, not on fill.** An unfilled condor was tracked
   as open, so the monitor tried to manage legs the broker did not hold.
4. **Ladder sign bug.** The final rung moved a credit further negative, asking for
   *more* credit and making a fill *less* likely.
5. **Critic vetoing valid trades.** The regime summary prescribed a structure, so
   when the EV optimiser chose a different one the LLM critic called it a
   contradiction. Regime strings are now descriptive.
6. **🔴 EV ignored transaction costs.** The biggest one. Every position the agent
   opened had a round-trip bid/ask *larger than the EV the gate required* — a
   condor needing \$8.82 of EV paid \$36 in spread. It was losing money by
   design. EV is now net of round-trip cost.
7. **Duplicate bets.** Two SPY condors opened with identical short strikes
   [755, 773]. One bet twice, paying the spread twice.
8. **🔴 Shared ledger across accounts.** The first COMP cycle read DEV's seven
   positions, so COMP's risk budget was consumed by another account's heat and
   every trade was rejected. The account would have sat flat with no error
   visible. The ledger is now per-account.

Bugs 2, 6 and 8 would each have been quietly expensive. 6 and 8 were found only
because I inspected single cycles instead of starting a loop.

## Bugs found after the first write-up

9. **Debit take-profit was unreachable.** A debit spread's max gain is several
   multiples of its cost, so taking profit at 75% of max gain demanded a 4-6.5x
   return — IWM's target was \$2,026 against \$512 paid. Those positions would
   have ridden to expiry with no profit rule governing them. Debit exits now
   measure against premium paid (+100%).
10. **Per-expiry cap silently throttled everything.** It is meant to stop
    concentration across expiries, but the deadline leaves only one usable
    expiry, so a 2.5% cap became the total limit while the intended 4% heat
    budget sat two-thirds unused. Every candidate was rejected with a sizing
    message that looked like ordinary caution.
11. **Directional debits were eating the carry.** Two IWM bear_puts plus an IBIT
    bull_call dragged -\$108/day against +\$143/day of credit income. The book is
    paid by time decay; spending that on directional bets means relying on being
    right about direction, which is not the edge we measured. A theta floor now
    polices theta-negative additions.
12. **launchd could not run the watchdog.** Its PATH is
    `/usr/bin:/bin:/usr/sbin:/sbin`, which excludes pyenv — a bare `python3`
    resolved to the system interpreter with no dependencies. Verified by running
    the script under `env -i` with launchd's exact environment.

## If you want to stop it

```bash
launchctl unload ~/Library/LaunchAgents/com.alpaca.optionsagent.plist
pkill -f "run.py loop"
```

To flatten the book immediately:
```bash
ACCOUNT=comp python3 run.py flatten --live
```

## Deadline handling is automatic

- **Thu 3 Sep 15:30 ET** — stops opening anything new
- **Fri 4 Sep 09:35 ET** — flattens the entire book, unconditionally, at higher
  priority than any other exit rule

The watchdog exists specifically so something is running at that second moment.
If the machine is asleep at 09:35 ET on Friday the flatten will not happen, and
the judged figure will drift with the market. **Leave the machine awake and
plugged in on Thursday night.**
